# Akamai Temporary Report Storage — AAP Test Cases

This document contains developer test cases for the temporary report-storage implementation that writes directly under `/tmp` inside the active AAP Execution Environment.

> Important:
> - Use the standalone playbook: `playbooks/akamai_version_push/report_storage.yml`
> - Use `Job Type = Check` only for check-mode scenarios. Do not try to set `ansible_check_mode` through Extra Vars.
> - The probe file is temporary and is removed after write/read/list validation.
> - The actual report file is not generated by this task. The task only validates storage and resolves the final report path.
> - `/tmp` is ephemeral and only valid for the lifetime of the current EE/container.

---

## Baseline Positive Extra Vars

```yaml
akamai:
  environment:
    name: qa

common_logging_request_id: "REPORT-TEST-001"
```

```text
SUCCESS
```
